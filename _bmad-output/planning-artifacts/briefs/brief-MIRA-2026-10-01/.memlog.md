- (event) Analyst Mary activada para elaborar Project Brief de MIRA (Entrega 2).
- (decision) Selección de funcionalidades: F4 (Puntaje y decisión por umbrales) y F1 (Bandeja de revisión asistida), fuertemente acopladas donde F4 produce los casos derivados que F1 consume.
- (decision) Aplicación vinculante de DEC-07 (H-04): Se prohíbe el rechazo automático. Todo caso con puntaje < 60 se deriva obligatoriamente a F1 para revisión humana significativa.
- (decision) Aplicación vinculante de DEC-04 (H-03): Umbrales de referencia fijados en >=90 (aprobación automática) y <90 (derivación a F1).
- (decision) Aplicación vinculante de DEC-03 (H-09): En la interfaz de F1, el puntaje se muestra al final, tras evidencia, alertas y desglose de señales, evitando el sesgo de anclaje.
- (insight) Resolución de hallazgo abierto H-12 (RF-11): Se operacionalizan los mínimos por señal individual para forzar derivación a F1 si una señal crítica falla aun con puntaje global alto.
- (decision) Precedencia de fraude (RF-12 / CP-RF-12-01): Señal de fraude activa fuerza derivación a F1 sin importar el puntaje.
- (decision) Información completa (RF-13 / CP-RF-13-01): Fallo de módulo deriva a F1 con indicación de faltante, nunca aprobación parcial.
- (direction) Exclusión estricta de alcance: Motores multimodales reales quedan simulados con datos de prueba (regla 4.3). Se excluyen F2, F3, F5, F6, F7, F8 y F9 para este incremento.
